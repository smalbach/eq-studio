Un 200 no es un test que pasa.

Endpoint Quality verifica cualquier API HTTP contra su contrato OpenAPI: status, schema, autenticación 401/403, persistencia real de lo que se escribe y flujos encadenados. Y la somete a carga, estrés, pico y resistencia.

Lo que un test de humo no ve

Cada respuesta se valida contra el schema que el propio contrato declara. Cada escritura se vuelve a leer. Cada operación protegida recibe sus casos 401 y 403.

Verificación funcional

Status y schema por operación, escrituras que se releen para comprobar que persistieron y flujos encadenados que limpian lo que crean.

Autenticación real

Casos 401 y 403 automáticos. Bearer, API key, basic, OAuth2, cookies, firma HMAC y mTLS, todo cifrado y nunca devuelto.

Carga, estrés, pico y resistencia

El mismo proyecto sirve para pruebas de rendimiento, con presupuestos de latencia por operación que nunca se inventan.

Casos negativos

De cada schema de entrada salen casos con una sola falta: campo ausente, tipo equivocado, fuera de rango, enum o formato.

Cualquier contrato

OpenAPI 3.0 y 3.1, Swagger 2.0 y colecciones de Postman. Entre dos versiones ves qué cambió y qué rompe clientes.

Local, CI y nube

Informes HTML, SARIF y JUnit, programaciones con avisos por Slack, webhook o email, y sincronización entre equipos.

De un contrato a una matriz en verde

Sin escribir tests a mano. El orden de ejecución corre las lecturas primero y los DELETE al final, para que un borrado roto no contagie de rojo al resto.

Importa el contrato

Pega la URL de tu openapi.json, sube un archivo o una colección de Postman.

Elige el entorno

URL base, si admite escrituras y las credenciales: principal, de permisos insuficientes y alternativa.

Corre la matriz

Empieza por la matriz GET; luego la completa, la de carga o llévala a tu CI con eq run.

También en la terminal y en tu CI

La CLI eq corre los mismos proyectos sin servidor. Sale con 0 si todo pasó y 1 si algún caso falló, y escribe JUnit, HTML y SARIF. Binarios de un solo archivo, sin Node:

macOS arm64 macOS x64 Windows x64 Linux x64 Linux arm64
sin instalar nada
# la app y el API en http://127.0.0.1:4400
npx endpoint-quality serve --open

# en CI: falla el job si el contrato no se cumple
npx endpoint-quality run --file proyecto.eq.json \
  --env staging --base-url "$URL" --token "$TOKEN" \
  --junit eq-report.xml --sarif eq.sarif
